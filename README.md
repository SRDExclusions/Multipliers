# Multipliers
This repository contains the replication code (.do file) and data series documentation for the study evaluating the macroeconomic impact of social protection spending in South Africa.

Publication Notice: This repository supports a working paper draft of a chapter accepted for publication in the forthcoming peer-reviewed book Social Security Review Volume 3, edited by Motala and Ngandu, to be published by the Department of Social Development in 2027.

How to Cite:
If you use or adapt the code or methodology provided in this repository, please cite the working paper as follows:
Baduza, S., Howson, K., & Tamukamoyo, H. (2026). The multiplier effect of social protection in South Africa. Institute for Economic Justice (IEJ). August 2026.

Usage and License:
This do-file is provided for academic and research purposes. Users are encouraged to utilize and stress-test the code in compliance with professional standards for transparent and ethical research reporting.

This repository also includes an excel spreadsheet of social grants budget data: "Master spreadsheet - multiplier.xls" 
These annual series for spending on grants were compiled using National Treasury's national and provincial data: 
*   **Data Source:** National Treasury
